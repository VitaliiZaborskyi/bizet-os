**Implemented pilot:** in EDIT after 4.5 s idle, small sinusoidal camera yaw drift with easing, amplitude 0.075 radians (about 4.3°). No automatic rear orbit. User pointer or wheel activity immediately interrupts. Auto motion stays disabled in VIEW and explicit object drag mode.

### #18 HANDLE-001..008 — Applied handle orientation vs hinge side
**Implemented:** canonical shared rule `appliedHandleOffset(hingeSide, placement)` supports `CENTER` or `OPPOSITE_HINGES`. Module editor exposes placement; changing hinge side automatically changes horizontal offset. Kitchen and fridge facade visuals share the rule. Applied handle is not added in Gola/edge/profile or push modes; profile geometry is visual-only and moving with facade pivot. Hinge visualization now follows the opening side, including two vertically stacked fridge fronts.
**OPEN:** exact supplier articles and profile machining remain unresolved, NOT inserted into production BOM as invented data.

### #19 HANDLE-OVR-001..006 — Tall/fridge individual handle system
**Implemented:** all ordinary kitchen modules inherit the global system; tall and built-in fridge modules expose `Inherit global` / `Individual` and options STANDARD / GOLA / EDGE / PROFILE / PUSH. Individual replaces global, never stacks. Overrides live in project visual settings module edits and are consumed by viewer/BOM. New UI fields localized RU/EN/UA.
**OPEN:** Exact Gola/profile vendor/processing profiles require separate source data, no factory claim.

### #20 FRIDGE / SUPPORT / PLINTH — Supports + common plinth
**Implemented:** shared `requiresFloorSupports` and `requiresCommonPlinth` rules. Kitchen builder renders 4/6 cylindrical supports for built-in fridge and other floor-standing tall units, adds plinth through tall/fridge frontage in normal/focus, and includes them in BOM. The black grille is shown in the PLINTH zone with exact nominal 460 × 60 mm; the Ø250 bottom-vent marker remains. For too-small geometry a diagnostic warning is emitted; no shrinking of the grille or false manufacturing file. Removed historic “plinth bypasses fridge” from BOM and acceptance tests.
