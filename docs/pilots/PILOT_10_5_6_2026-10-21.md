## Visualization setup (owner action required; no secrets in repo)

- Set Render service secrets `OPENAI_API_KEY` and `BIZET_VISUALIZATION_ACCESS_CODE`. Values must be owner's, never written in GitHub.
- Optional `BIZET_VISUALIZATION_MODEL` (default `gpt-image-1`). The provider uses /v1/images/edits with PNG reference, server-enforced instructions and 1536×1024 medium-quality output.
- `GET /api/v1.1/visualization/status` reports `ready:false` when either credential missing. `POST /api/v1.1/visualization/generate` requires owner code and rate limits 90sec/IP, 12/day/IP.
- The user cannot edit locked base prompt. User may add only non-structural stylistic requirements. Both a rendered screenshot and the scene JSON accompany the provider request.
- Even with provider: AI output may deviate from original geometry; compare against the canonical source and do not use it as machine data.
